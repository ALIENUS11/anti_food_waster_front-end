## 三、接口返回体：`RiskForecastData`

`GET /hall3/risk-forecast`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `cadenceMinutes` | number | ✅ | 采样间隔（30 min） |
| `totalMinutes` | number | ✅ | 时间轴总长（54 h = 3240 min） |
| `forecastStartMinute` | number | ✅ | 预测起点（出发后 36 h = 2160 min），画竖线用 |
| `forecastStartTime` | string | ✅ | 预测起点的文本（第2天 20:30） |
| `forecastRangeLabel` | string | ✅ | 预测范围文本（第2天 20:30 – 第3天 14:30（18 小时）） |
| `thresholdOptions` | number[] | ✅ | 阈值档位（`[40, 50, 60]`），界面可现场切换 |
| `defaultThreshold` | number | ✅ | 默认阈值（50） |
| `samples` | `SeriesSample[]` | ✅ | **长表时序**：一条记录 = 指标 + 时间 + 数值 + 状态（109 时刻 × 5 指标 = 545 条） |
| `riskCurve` | `RiskPoint[]` | ✅ | 霉变 / 受潮 / 品质下降概率曲线（109 点） |
| `metricMeta` | `MetricMeta[]` | ✅ | 指标元数据：名称、单位、数据来源、判定规则 |
| `judgeRules` | `JudgeRule[]` | ✅ | 判定规则（5 条），界面上「判定规则与阈值」面板用它 |
| `nodeTicks` | `RiskNodeTick[]` | ✅ | 关键风险节点刻度（6 个），带环境与风险快照 |
| `updatedAt` | string | ✅ | 数据更新时间（顶部栏显示） |

**约束（前端自检脚本逐条校验）**

- `samples[].minute` 与 `riskCurve[].minute` 必须一一对应（同一套时间轴）；
- 每个 `minute` 上必须齐 5 个指标（温度 / 湿度 / 震动 / 运输时长 / 天气）；
- `samples[].phase`：`minute >= forecastStartMinute` 为 `'预测'`，否则 `'历史'`；
- 预测阶段的温度、湿度必须带 `lower` / `upper`（置信区间）；
- `nodeTicks[].minute` 必须等于 3-1 `legs.durationH` 的累计值（6 个节点：0 / 36 / 156 / 942 / 2484 / 3204 分钟）；
- **高风险时段不写在数据里**：页面按当前阈值从 `riskCurve` 上实时算（连续超阈区间）。

## 四、`SeriesSample`（长表时序）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `metric` | `'temperature' \| 'humidity' \| 'vibration' \| 'duration' \| 'weather'` | ✅ | 指标标识 |
| `name` / `unit` | string | ✅ | 指标名称（温度 / 湿度 / 震动 / 运输时长 / 天气）与单位 |
| `minute` | number | ✅ | 统一时间轴上的分钟数 |
| `time` | string | ✅ | 时间文本（第N天 HH:mm） |
| `label` | string | ✅ | 数值标签（`31.8℃`、`86%RH`、`阵雨`） |
| `value` | number | ✅ | 数值（天气取 `WEATHER_ORDER` 的下标） |
| `status` | `RouteRiskLevel` | ✅ | **该条数据的状态**（按指标各自的判定规则算） |
| `phase` | `SeriesPhase` | ✅ | 历史 / 预测 |
| `events` | string[] | ✅ | 风险事件标签（如 `['港区阵雨']`） |
| `lower` / `upper` | number | ➖ | 预测阶段的置信上下界（仅温度、湿度） |

## 五、其余类型

**`MetricMeta`**：`key`、`name`、`unit`、`source`（数据来源）、`rule`（判定规则文字）。

**`RiskPoint`**：`minute`、`time`、`phase`、`moldRisk`、`dampRisk`、`qualityDrop`（%）。

**`RiskNodeTick`**：`nodeId`、`name`、`minute`、`time`、`temperature`、`humidity`、`vibration`、`weather`、`moldRisk`、`dampRisk`、`level`、`desc`。

**`JudgeRule`**：`id`、`name`、`condition`、`effect`、`level`。

## 六、当前常量速查

**时间轴**：0–54 h（第1天 08:30 → 第3天 14:30），30 min 采样，109 个时刻；历史段 0–36 h，预测段 36–54 h（18 h）。

**关键风险节点（取自 3-1 的线路与累计时长）**

| 节点 | 时刻 | 累计分钟 | 该时刻环境快照 | 风险结果 |
| --- | --- | --- | --- | --- |
| 南昌 · 产地粮库 | 第1天 08:30 | 0 | 26.0℃ / 62%RH / 晴 | 低风险 |
| 昌北枢纽 | 第1天 09:06 | 36 | 28.9℃ / 66%RH / 晴 | 低风险 |
| 九江港 · 装船 | 第1天 11:06 | 156 | 33.2℃ / 74%RH / 多云 | 中风险 |
| 安庆 · 航道中转 | 第2天 00:12 | 942 | 26.3℃ / 76%RH / 多云 | 低风险 |
| 上海港 · 转海运 | 第3天 01:54 | 2484 | 24.3℃ / 84%RH / 阴 | 中风险 |
| 宁波 · 销区中转粮库 | 第3天 14:30 | 3204 | 28.1℃ / 72%RH / 多云 | 低风险 |

**风险概率算法（界面上的因果关系）**

```
受潮风险 = clamp((湿度 − 62) × 1.9, 0, 100)                     // 62%RH 起算
霉变风险 = clamp((温度 − 24) × 3.2 + (湿度 − 70) × 1.5, 0, 100)  // 高温 + 高湿叠加
品质下降 = clamp((霉变 + 受潮) ÷ 2 + 3, 0, 100)                  // 两者综合
```

**判定规则 5 条**：高温霉变（温度 ≥32℃ 持续 2 h）、高湿受潮（湿度 ≥85%RH 持续 2 h）、装卸冲击（震动 ≥1.0g）、在途超时（运输时长 ≥48 h）、恶劣天气（阵雨/团雾/大风）。

**阈值与等级**：默认阈值 50%（可切 40 / 50 / 60）；`低风险 < 阈值−12`、`中风险 阈值−12 ~ 阈值`、`高风险 ≥ 阈值`；高风险时段由页面按阈值实时算，界面用色块标出。
