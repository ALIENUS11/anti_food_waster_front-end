## 二、通用约定（单位 / 格式）

| 项目 | 约定 | 示例 |
| --- | --- | --- |
| 经纬度 | `[经度, 纬度]`，number 数组，WGS84 十进制度 | `[115.88, 28.68]` |
| 距离 | number，单位 **km** | `982` |
| 时长 | number，单位 **小时 h** | `53.4` |
| 损耗率 | number，**不带 % 符号**，各段相加 = 全程损耗率 | `2.1` 表示 2.1% |

| 载重 / 车速 | number，单位 **t / t / km/h** | `28.5`、`58` |
| 时间点 | string，**`YYYY-MM-DD HH:mm`**（本地时间，不带时区） | `'2026-09-24 08:30'` |

## 三、接口 1 返回体：`RoutePlanData`

`GET /hall3/route-plan`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `startName` / `endName` | string | ✅ | 起点 / 终点名称 |
| `nodes` | `RouteNode[]` | ✅ | 关键节点（本次 6 个：南昌产地 → 昌北枢纽 → 九江港 → 安庆 → 上海港 → 宁波） |
| `legs` | `RouteLeg[]` | ✅ | 路段，数组顺序即行驶顺序；`mode` 决定运输方式与线色 |
| `envZones` | `EnvZone[]` | ✅ | 环境风险区（本次 5 个），可为空数组 |
| `layers` | `MapLayer[]` | ✅ | 地图图层定义（底图 / 路线 / 节点 / 环境） |
| `modes` | `TransportModeInfo[]` | ✅ | 三段运输方式说明（3D 场景、平均速度、该段合计损耗） |
| `lossBreakdown` | `LossSegment[]` | ✅ | 分段损耗（总览视图的柱状 + 折线数据源） |
| `summary` | `RouteSummary` | ✅ | 总览结论：总损耗、四类风险来源、里程碑、建议 |
| `vehicle` | `VehicleInfo` | ✅ | 公路段载具（卡车） |
| `vessel` | `VesselInfo` | ✅ | 水运 / 海运段载具（货船） |
| `info` | `RouteInfo` | ✅ | 全程距离、时长、风险等级与说明 |
| `departAt` / `etaAt` | string | ✅ | 计划出发 / 到达时间 |
| `updatedAt` | string | ✅ | 页面右上角更新时间 |

**约束（后端返回时也要满足，前端自检脚本逐条校验）**

- `legs[].fromId / toId` 必须存在于 `nodes`；
- `nodes[].zoneId` 必须存在于 `envZones`；
- `Σ legs.distanceKm = info.distanceKm`（当前 982）；
- `Σ legs.durationH = info.durationH`（当前 53.4）；
- `Σ lossBreakdown.distanceKm = info.distanceKm`、`Σ lossBreakdown.durationH = info.durationH`；
- `Σ lossBreakdown.lossRate = summary.totalLossRate`（当前 2.10）；
- `Σ lossBreakdown.lossKg = summary.totalLossKg`（当前 599）；
- `Σ modes.distanceKm = info.distanceKm`；
- `summary.milestones[].nodeId` 必须存在于 `nodes`；`summary.advices` 固定 3 条；`summary.riskSources` 固定四类（天气 / 道路 / 节点 / 环境）。

## 八、总览相关：`LossSegment` / `RouteSummary`

**`LossSegment`（分段损耗）**：`id`、`name`、`mode`、`distanceKm`、`durationH`、`lossRate`、`lossKg`、`riskLevel`、`note`（口径说明）。

**`RouteSummary`**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `totalLossRate` | number | 全程损耗率 %（= 各段之和） |
| `totalLossKg` | number | 全程损耗量 kg |
| `riskSources` | `RiskSourceGroup[]` | 四类风险来源：`kind`（天气/道路/节点/环境）、`count`、`items[]` |
| `milestones` | `Milestone[]` | 关键节点回顾：`time`（`第N天 HH:mm`）、`title`、`desc`、`nodeId` |
| `conclusion` | string | 总览结论一段话 |
| `advices` | string[3] | 减损建议，固定 3 条 |

**`VehicleInfo`**：`plate`、`model`、`loadTon`、`capacityTon`、`avgSpeedKmh`。
**`VesselInfo`**：`name`、`type`、`capacityTon`、`batchTon`、`speedKmh`。
**`RouteInfo`**：`distanceKm`、`durationH`、`riskLevel`、`riskDetail`、`riskZoneId?`。
**`MapLayer`**：`id`（`basemap` / `route` / `nodes` / `env`）、`name`、`type`、`source`、`visible`、`desc`。

## 九、接口 2 返回体：`BasemapData`（离线底图）

`GET /hall3/basemap`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `source` | string | ✅ | 底图来源说明，显示在地图左上角 |
| `bounds` | `{ minLng, maxLng, minLat, maxLat }` | ✅ | 投影范围，决定经纬度 → 画布坐标 |
| `geojson.type` | `'FeatureCollection'` | ✅ | 固定值 |
| `geojson.features[].properties.kind` | `GeoKind` | ✅ | `'land'` 陆地、`'province'` 省界、`'sea'` 海域、`'river'` 河道、`'lake'` 湖泊、`'coast'` 海岸线、`'road'` 公路 |
| `geojson.features[].geometry` | `Polygon{[number,number][][]}` \| `LineString{[number,number][]}` | ✅ | 面或线 |

**取景说明**：当前 `bounds = { minLng: 113.4, maxLng: 123.1, minLat: 27.25, maxLat: 32.45 }`，
覆盖江西及周边走廊（南昌、九江、鄱阳湖、长江九江→上海水道、长江口、杭州湾/宁波）；
赣州及以南不在取景范围内 —— 16:9 大屏装不下完整江西全省，若甲方要求全省，需改「全省缩略图 + 走廊放大图」双图布局。

**替换标准地理数据时**：只改 `src/mock/hall3/basemap.ts` 的 `features` 与 `bounds`，
`kind` 取值与 GeoJSON 结构保持不变即可，页面、投影、3D 代码都不用动。
