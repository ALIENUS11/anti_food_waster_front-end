# 5-1 数字化食堂浪费场景警示展示 —— 视频素材放这里

把视频文件直接放在本目录下，文件名要和 `src/mock/hall5/canteen-warning.ts` 里配的 `src` 一致：

| 文件名 | 场景 |
| --- | --- |
| `canteen-01.mp4` | 取餐 |
| `canteen-02.mp4` | 用餐 |
| `canteen-03.mp4` | 剩餐回收 |
| `canteen-04.mp4` | 光盘行动对比 |

## 注意

- **必须是本地文件，不能引用外链。** 展厅是离线环境，外链打不开。
- 文件放进来后页面会自动切换成真实播放，**代码一行都不用改**；没有文件时，缺素材的那一段会走「演示模式」的虚拟时间轴，播放控制照常可以演示。
- 要加一段 / 改文件名 / 改播放顺序，只改 `src/mock/hall5/canteen-warning.ts` 里的 `videos` 数组即可。
- 建议 H.264 编码的 mp4（展厅大屏和触控屏的浏览器都认），1080p 及以上。
- 进入页面时会把所有视频一起预加载（这样切换场景不会出现黑场、声音也不会断），所以单个文件别太大。
